# Referencia

Todo lo que se sabe de tu producto, sacado de Figma. Se llena en las fases 2 a 6.

- `_inventario.json`: todas las pantallas del archivo de Figma y cuáles están descargadas (fase 2).
- `<seccion>/capturas/`: las imágenes de cada pantalla (fase 3).
- `galeria.html`: ábrela con doble clic para ver flujos, pantallas y sistema visual (`python3 tools/build_gallery.py`).
- `FLUJOS.md` y `flujos.json`: qué tareas se hacen en el producto y con qué pantallas (fase 4).
- `<flujo>/notas.md`: lo que se sabe de cada flujo; `<flujo>/codigo/`: el código que da Figma de sus pantallas (fases 4-6).

Esta carpeta contiene tu producto. Si guardas tu copia del kit en GitHub, que sea en un repositorio privado.
